# Хот Спот для Rokid RV101

Русская адаптация интерфейса и ручного выбора из [Rokid Wi-Fi Selector](https://github.com/ksuzukigh/rokid-wifi-selector) с сохранением отдельного AIUI-агента «Хот Спот» и локального Android-моста.

## Что делает приложение
- Показывает текущую Wi-Fi сеть и доступные сохранённые сети.
- Позволяет выбрать сеть свайпом и подключиться касанием, как в оригинальном Selector.
- Запускает фоновый локальный мост на `127.0.0.1:38762`, которым пользуется AIUI-агент.
- Проверяет фактический SSID после переключения; тайм-аут — 15 секунд, после неудачи пытается вернуть прежнюю сеть.
- Не запрашивает и не хранит пароли Wi-Fi.

## Голосовые команды
- «Хот Спот, какая сейчас сеть?»
- «Хот Спот, покажи доступные сети»
- «Хот Спот, подключись к Studio» → SSID `Studio`
- «Хот Спот, подключись к Local Network» → SSID `Local_Network_5G`
- «Хот Спот, включи Wi-Fi»

Сети должны быть заранее добавлены в очки через Hi Rokid. Агент не подменяет и не меняет их пароли.

## Первый запуск
1. Установить APK через Hi Rokid.
2. Один раз открыть «Хот Спот».
3. Разрешить доступ к геоданным — Android требует это для чтения SSID и списка Wi-Fi.
4. После этого локальный мост работает как фоновый сервис и запускается после перезагрузки.

## Состав
- `android/` — Android-приложение и локальный мост.
- `aiui/` — исходники голосового AIUI-агента (если включены в эту ветку).
- Основа переключения: проект Rokid Wi-Fi Selector, MIT License.

## Ограничения
В основе используется `WifiManager.enableNetwork()`. Прошивка YodaOS может ограничивать переключение сетей для обычных приложений. Сборка APK не доказывает, что конкретная прошивка разрешит фоновое переключение; окончательная проверка нужна на самих очках.
